CODE STATION

Приклад програми Arduino для миготіння світлодіода. Скопіюй код і спробуй запустити його в Arduino IDE або Tinkercad.

BLINK.ino
ARDUINO C++ 
void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);

  digitalWrite(13, LOW);
  delay(1000);
}
● READY TO COPY
01 / SETUP

pinMode(13, OUTPUT) налаштовує контакт 13 як вихід, до якого можна підключити світлодіод.

02 / LOOP

Функція loop() постійно повторює команди, поки Arduino увімкнена.

03 / RESULT

Світлодіод вмикається на одну секунду, вимикається на одну секунду і повторює цикл.
